# 乒乓球位置控制 Android App

## 功能

这个 App 直接连接 ESP32 WiFi/蓝牙二合一透传模块的 WiFi TCP 端口，不依赖商家 App，也不需要电脑网页桥接。

当前通信链路：

```text
MSPM0 UART2 -> ESP32 透传模块 -> 手机 WiFi -> Android App
```

App 会解析 MSPM0 上传的数据帧：

```text
T,ms,active,target_cm,current_cm,pwm
```

并显示：

- 运行状态
- 目标距离
- 实测距离
- PWM 输出
- 目标/实测实时曲线

同时可发送控制命令：

```text
RUN
STOP
UP
DOWN
SET 50
GET
```

实测结果：App 启动/停止、目标增减和 SET 命令均可控制单片机；实体按键改变状态后，App 也能同步显示。

## 模块默认连接参数

- WiFi 名称：`Makerobo`
- WiFi 密码：`12345678`
- 模块 IP：`192.168.1.1`
- TCP 端口：`2001`
- 串口波特率：`115200`

App 默认填写：

```text
IP:   192.168.1.1
Port: 2001
```

如果商家资料或实际测试端口不同，在 App 界面直接修改即可。

## 接线

| MSPM0G3507 | ESP32 透传模块 | 说明 |
| --- | --- | --- |
| PB15 / UART2_TX | RXD | MSPM0 上传遥测数据 |
| PA22 / UART2_RX | TXD | App 下发控制命令 |
| GND | GND | 必须共地 |
| 5V | VCC | 按商品页供电 |

注意：模块 VCC 是 5V，但 UART 通常是 3.3V TTL。若实测模块串口电平为 5V，需要给 MSPM0 RX 加电平转换或限流保护。

## 使用步骤

1. 给 MSPM0 和 ESP32 透传模块供电。
2. 手机 WiFi 连接模块热点，例如 `Makerobo`，密码 `12345678`。
3. 如果系统提示“该 WLAN 无法访问互联网”，选择继续使用该网络。
4. 打开 App，确认 IP 为 `192.168.1.1`、端口为 `2001`。
5. 点击“连接”。
6. 如果 MSPM0 正常发送数据，App 日志会出现 `RX T,...`，卡片和曲线会刷新。
7. 点击 `启动` / `停止`，OLED 状态应切换 `ACTIVE/STANDBY`。
8. 点击 `+5 cm` / `-5 cm` / `SET`，OLED 目标距离应同步变化。

## UART2 接收修复

早期版本使用主循环轮询 UART2 接收数据，实测中会因 OLED 刷屏、超声波测距等待等耗时任务造成 UART FIFO 溢出，表现为 App 日志显示 `TX RUN`，但单片机只收到换行符，无法执行命令。

当前单片机程序已改为：

```text
UART2 RX 中断 -> 128 字节软件环形缓冲区 -> 主循环解析命令
```

修复后，无线控制启停和目标距离调节已经通过实测。

## 常见问题

### 点击连接失败

- 确认手机已经连接模块 WiFi。
- 确认 Android 系统没有自动切回有互联网的 WiFi。
- 确认 IP 和端口是否为 `192.168.1.1:2001`。

### 能连接但没有数据

- 检查 MSPM0 `PB15/UART2_TX` 是否接到模块 `RXD`。
- 检查 GND 是否共地。
- 检查 MSPM0 UART2 波特率是否和模块一致。

### 能收到数据但按钮无效

- 检查模块 `TXD` 是否接到 MSPM0 `PA22/UART2_RX`。
- 检查 App 日志是否有 `TX RUN`、`TX SET 50`。
- 确认单片机固件已使用 UART2 中断 + 环形缓冲接收。

### 手机连接模块 WiFi 后没有网络

这是正常现象。透传模块热点只用于局域通信，不提供互联网。Android 弹窗时要选择“继续使用此 WLAN”。

### 曲线显示占满后不明显滚动

当前 App 曲线采用固定点数缓存，长时间运行后视觉上会铺满显示区域。该问题不影响控制功能，后续可改为最近 30 秒或 60 秒的滑动时间窗口显示。
