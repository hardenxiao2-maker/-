# 参数调节功能说明

本文档说明新版 Android App 参数页、校准页与单片机 `CFG` / `CAL` 命令的对应关系。

## 1. 总体机制

单片机运行参数仍然以程序默认值启动。为了避免频繁改代码、重新烧录，App 新增了在线参数调节功能：

```text
App 参数页/校准页填写数据
-> 保存到手机本地 SharedPreferences
-> 通过 WiFi TCP 或蓝牙 SPP 发送到 ESP32 透传模块
-> ESP32 通过 UART2 转发给 MSPM0
-> MSPM0 在运行时更新 PID、PWM、温度和测距校准表
```

单片机断电后会恢复默认参数，但 App 每次连接成功后会自动重新发送手机本地保存的参数，因此可以达到“调试效果由 App 保存”的效果。

## 2. 参数页字段说明

| App 字段 | 单片机命令 | 作用 | 调试建议 |
| --- | --- | --- | --- |
| `Kp` | `CFG,KP,x` | 比例系数，决定误差响应强度 | 先调 Kp，过小响应慢，过大容易振荡 |
| `Ki` | `CFG,KI,x` | 积分系数，用于消除长期静差 | 最后少量加入，过大容易慢性振荡 |
| `Kd` | `CFG,KD,x` | 微分系数，用于抑制超调 | Kp 基本合适后再加 Kd |
| `base_pwm` | `CFG,BASE_PWM,x` | 基础风量，PID 输出叠加在它上面 | 先调到小球接近悬浮所需风量 |
| `pwm_min` | `CFG,PWM_MIN,x` | PWM 下限 | 通常保持 0 |
| `pwm_max` | `CFG,PWM_MAX,x` | PWM 上限 | 防止风机过强把球吹出 |
| `safe_pwm` | `CFG,SAFE_PWM,x` | 测距失败时使用的安全低风量 | 建议低于正常悬浮风量 |
| `filter_alpha` | `CFG,FILTER_ALPHA,x` | 测距一阶滤波系数 | 0.2-0.5 常用，越大响应越快但更抖 |
| `target_min` | `CFG,TARGET_MIN,x` | 目标距离下限 | 按题目一般设 30 |
| `target_max` | `CFG,TARGET_MAX,x` | 目标距离上限 | 按题目一般设 70 |
| `step_cm` | `CFG,STEP,x` | App UP/DOWN 每次调节步长 | 默认 5cm |
| `temperature` | `CFG,TEMP,x` | 温度补偿参数 T | 按现场温度填写 |

温度参数影响两件事：

```text
1. HC-SR04 声速补偿：v = 331.4 + 0.6*T
2. 多温度测距校准表选择/插值
```

## 3. 校准页字段说明

校准页用于填写“超声波测得值 -> 真实距离”的映射表。

示例：

```text
真实距离 20cm 时，超声波读数为 19.2cm
真实距离 25cm 时，超声波读数为 24.1cm
真实距离 30cm 时，超声波读数为 28.9cm
```

则在 App 校准页填写：

```text
测距值 19.2 -> 真实值 20.0
测距值 24.1 -> 真实值 25.0
测距值 28.9 -> 真实值 30.0
```

App 会发送：

```text
CAL,TEMP,25
CAL,POINT,0,19.2,20.0
CAL,POINT,1,24.1,25.0
CAL,POINT,2,28.9,30.0
...
CAL,APPLY
```

单片机会先写入临时表，只有 `CAL,APPLY` 校验通过后才正式启用。要求测距值必须从小到大递增。

## 4. 推荐调试顺序

1. 先在 App 参数页填写现场温度，例如 `25`。
2. 静态测距，记录 20cm、25cm、30cm……70cm 的超声波读数。
3. 在校准页填写测距值和真实值，点击“发送并应用”。
4. 观察 OLED 调试页：
   - `RX` 增加：说明 UART2 收到数据。
   - `CMD` 变化：说明命令被解析。
   - `CFG` 增加：说明参数设置成功。
5. 调 `base_pwm`，让球在目标附近具备基础悬浮能力。
6. 调 `Kp`，让球能快速靠近目标。
7. 加少量 `Kd`，抑制超调和振荡。
8. 最后加少量 `Ki`，消除长期静差。
9. 在曲线页观察：
   - PID tracking 中实际距离是否贴近目标距离。
   - error 曲线是否逐渐接近 0。
   - Fan speed RPM 是否随 PWM 合理变化。

## 5. 自动保存与自动同步

点击参数页“发送参数”或校准页“发送并应用”时，App 会先把数据保存到手机本地。

以后每次连接 WiFi 或蓝牙成功后，App 会自动发送保存的参数：

```text
CFG,KP...
CFG,KI...
CFG,KD...
CFG,TEMP...
CAL,TEMP...
CAL,POINT...
CAL,APPLY
CFG?
GET
```

因此，现场调好参数后，只要不卸载 App，参数就会留在手机里；单片机重新上电后连接 App，即可恢复上一次调试效果。

## 6. OLED 调试页

当前 `empty.c` 中：

```c
#define OLED_REMOTE_DEBUG_MODE (1)
```

表示 OLED 显示远程通信调试页：

```text
RX:累计接收字节数 L:累计命令行数
CMD:最近收到的一条命令
T:当前温度 Kp:当前Kp
CFG:成功设置参数次数 RPM:风机转速
```

如果 App 连接后自动同步成功，`RX`、`L`、`CMD`、`CFG` 都会变化。

确认下行链路和参数同步都正常后，把 `OLED_REMOTE_DEBUG_MODE` 改成 `0`，即可恢复比赛正常 OLED 页面。
