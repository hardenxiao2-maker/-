# 乒乓球位置控制与悬停系统 - 程序功能与原理说明书

## 一、 系统概述

本程序是基于德州仪器（TI）MSPM0G3507 微控制器开发的“乒乓球位置控制与悬停装置”核心固件。程序通过 HC-SR04 超声波传感器实时采集乒乓球在导管内的相对高度（距离），经由内部运算模块进行一阶低通滤波和 PID 闭环计算后，输出两路高频 PWM 信号控制涡轮风机。风机产生的上升气流与乒乓球重力相抵消，从而实现乒乓球在 30cm~70cm 区间内的精准定点悬停与动态高度调节。

---

## 二、 核心程序文件与功能解析

整个软件系统采用**高内聚、低耦合**的模块化设计思路，核心代码分布在三个主要文件中：

### 1. 任务调度与系统主干 (`empty.c`)
这是程序的入口与主循环所在文件，主要承担外设初始化、任务调度、人机交互与状态显示的职能。

*   **硬件初始化**：调用 SysConfig 生成的 `SYSCFG_DL_init()` 初始化时钟、GPIO、I2C 和 PWM 外设。随后依次初始化 OLED 屏幕、超声波引脚和悬停控制状态机。
*   **微秒级高精度时基 (`micros`)**：利用 Cortex-M0+ 的 SysTick（系统滴答定时器，1ms 中断一次，向下计数），结合中断计数值和当前寄存器 `VAL` 余值，拼接出极其精准的微秒级时间戳（`uint32_t`），为整个系统的超时检测和 PID 积分提供时间基准。
*   **非阻塞时间片轮询架构**：摒弃了传统的 `delay_ms` 死等待阻塞方式，采用时差判断的方法进行多任务调度：
    *   **极速按键轮询**：在 `while(1)` 根部直接读取 GPIO 状态。由于没有延时阻塞，按键响应速度达到微秒级，配合状态机标志位（如 `s_btn1_active`）实现精准的边沿触发（防连按）。
    *   **高频控制环（20Hz）**：每隔 50,000 微秒（50ms）严格调用一次 `Hover_Control_Tick()`，保证控制算法的等距采样。
    *   **低频显示环（5Hz）**：每隔 200,000 微秒（200ms）调用一次 OLED 刷新。I2C 刷屏耗时较长（约 10~15ms），将其降频至 5Hz 既能让人眼看清数据流，又极大释放了 CPU 算力，防止干扰 PID 控制的实时性。

### 2. 位置反馈采集模块 (`hc_sr04.c`)
专门负责超声波传感器的驱动与数据读取。

*   **非阻塞超时测距**：通过 PB12 (Trig) 发出 10us 的高电平触发信号，随后使用 `micros()` 记录 PB13 (Echo) 保持高电平的持续时间。
*   **死锁保护机制**：在等待 Echo 电平跳变的过程中，如果等待时间超过 30,000 微秒（约 30ms，对应物理距离 >5 米），函数会自动超时退出并返回 `-1.0f`。这防止了因传感器断线或前方无遮挡物导致主循环死锁停摆。

### 3. 闭环控制与运算核心 (`hover_ctrl.c`)
这是整个装置的“大脑”，包含了传感器数据的滤波处理、系统状态机管理以及 PID 核心控制算法。

*   **系统启停与安全状态机**：系统上电默认处于 `STANDBY`（待机）模式，此时风机 PWM 输出强制为 0，且 PID 积分器清零。但超声波测距依然工作，以便在 OLED 上演示“静态测距”功能。一旦传感器返回错误，系统也会自动接管并输出一个较低的“安全风速（PWM=150）”，防止小球突然冲顶飞出。
*   **动态步长调节**：提供 `Hover_IncreaseTarget` 和 `Hover_DecreaseTarget` 接口，在 `empty.c` 捕获按键时调用。内置 30.0cm 至 70.0cm 的软限幅，确保设定的目标高度始终在题目规定的合理安全范围内。

## 三、 关键算法原理详解

### 1. 一阶指数平滑滤波 (EMA Low-Pass Filter)
超声波传感器在管内测量曲面的乒乓球时，容易因声波乱反射产生 ±1~2cm 的随机跳变噪声（白噪声）。如果不加处理，这种高频噪声会通过 PID 的微分项（D）被成百上千倍地放大，导致风扇发出刺耳的颤音。
*   **公式**：`s_current_height = 0.35 * 新测量值 + 0.65 * 历史平滑值`
*   **原理**：当前采用的高度数据融合了 35% 的最新测距值和 65% 的历史惯性值。这相当于一个低通滤波器，有效过滤了瞬间的突变尖峰噪声，同时保留了小球真实移动的低频轨迹，使得控制更加顺滑。

### 2. 动态自适应 dt 计算
在离散化的 PID 公式中，积分（I）和微分（D）的计算都强依赖于时间步长 `dt`。传统做法是假定 `dt` 是一个常数（例如 0.05 秒）。
*   **痛点**：若系统偶尔被外部中断（如 OLED 刷新或按键抖动）打断，真实的物理流逝时间大于 0.05 秒，若依旧按常数计算，会导致积分累加不足、微分计算偏大，进而引发系统震荡。
*   **本程序方案**：在每次进入 `Hover_Control_Tick` 时，调用 `micros()` 获取当前绝对时间，与上一次的时间戳相减，**实时计算出真实的微秒级 dt**（如 0.052 秒或 0.065 秒）。将其代入 PID 公式，彻底消除了调度抖动带来的数学误差。

### 3. 增量式与位置式融合的 PID 控制
*   **基础前馈重力补偿**：`output = s_base_pwm + P_out + I_out + D_out;`
    代码中预设了 `s_base_pwm = 350.0f`。这代表了“恰好能吹起乒乓球抵抗重力”的盲区基础 PWM 值。有了这个前馈量，PID 算法只需关注误差的动态微调，大大加快了系统从静止到悬停的收敛速度。
*   **比例控制 (P - 22.0)**：根据当前高度与目标高度的差值（Error），产生主要的驱动力。误差越大，风机加速越猛。
*   **积分控制 (I - 1.5) 与抗积分饱和**：用于消除稳态误差。若导管发生倾斜导致阻力增加，P 控制无法完全克服时，I 控制会随着时间累加误差，逐渐增加风力直到球达到绝对目标位置。同时代码中加入了 `integral_max = 200` 的限幅（Anti-windup），防止长时间堵转或大偏差引起的积分值爆炸（俗称“积分风暴”）。
*   **微分控制 (D - 6.0)**：起阻尼刹车作用。通过计算误差的变化率 `(error - error_prev) / dt` 来预测小球的运动趋势。当小球快速接近目标高度时，微分项会产生负向输出，提前减弱风力，防止小球冲过头（超调）。

## 四、 用户操作指南

1.  **系统上电**：给设备供电后，OLED 屏幕亮起显示 `-- Hover Demo --`。此时系统处于 `STANDBY` 状态，风机不转，但您可以上下移动乒乓球，屏幕上的 `Actual: xx.x cm` 会实时精准显示当前距离（静态测距演示功能）。
2.  **设定目标高度**：
    *   按下 **按键 2 (PA29, Up)**：目标悬停高度（Target）增加 5cm（最高限制至 70cm）。
    *   按下 **按键 1 (PB25, Down)**：目标悬停高度（Target）降低 5cm（最低限制至 30cm）。
3.  **启动悬停**：按下 **按键 3 (PB26, OnOff)**，系统状态切换为 `ACTIVE`。风机启动，并在 PID 算法的控制下，将乒乓球迅速吹起并稳定悬停在 Target 指定的高度。
4.  **动态调节**：在 `ACTIVE` 状态下，您依然可以随时按下按键 1 或 2，目标高度会立刻改变，乒乓球会在空中平稳地下降或上升至新的 5cm 档位处。
5.  **抗干扰测试**：在悬停时，若用手轻轻拨动乒乓球或轻微倾斜底座，系统会瞬间检测到高度误差，并在 1~2 秒内自动加大或减弱风速，重新将球拉回原定悬停高度。
